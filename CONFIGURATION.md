# Configuration Reference Manual

This document explains every configuration setting across the frontend application (`config/config.json`) and the Google Apps Script backend (**Script Properties**).

---

## 1. Frontend Configuration (`config/config.json`)

| Setting Key | Type | Example | Description |
|---|---|---|---|
| `endpointUrl` | `string` | `https://script.google.com/macros/s/AKfycb.../exec` | The public HTTPS Web App deployment URL generated by Google Apps Script. |
| `sharedToken` | `string` | `"my-secret-token-123"` | Low-value anti-drive-by token. Sent in the payload header to match the backend `SHARED_TOKEN`. |
| `submitTimeoutMs` | `number` | `60000` | HTTP request timeout in milliseconds (default: 60,000 ms to accommodate base64 resume uploads). |
| `retryAttempts` | `number` | `2` | Number of automatic retries on network drop or HTTP 5xx error. |
| `successMessage` | `string` | `"Thank you! Your application has been received."` | Custom text displayed on the success screen after submission. |
| `successRedirectUrl` | `string` | `""` | Optional URL to redirect candidates to after 3 seconds upon successful submission. Leave empty to disable. |
| `showSubmissionId` | `boolean` | `true` | Whether to display the unique client-generated UUID on the success screen. |
| `saveDraftLocally` | `boolean` | `true` | Enables debounced autosaving of form field inputs to browser `localStorage`. |
| `antiSpam.honeypotField` | `string` | `"company_website"` | Form control name used as a hidden bot honeypot. |
| `antiSpam.minFillSeconds` | `number` | `3` | Minimum time in seconds candidates must spend on the page before submitting. |
| `branding.primaryColor` | `string` | `"#00a699"` | Hex color code applied to buttons, links, and highlight states. |
| `branding.footerText` | `string` | `"© 2026 IndiaMART InterMESH Ltd."` | Custom footer text. |

> [!NOTE]
> `config/config.json` is committed to version control and delivered to candidate browsers. It must **never contain confidential credentials or API secrets**.

## 2. Backend Script Properties (Google Apps Script)

Configure these key-value pairs in **Apps Script Project Settings** → **Script Properties**:

| Script Property Key | Example Value | Description |
|---|---|---|
| `SPREADSHEET_ID` | `12zL8uoISWtPDURgyvLHtfO-eM5UEx_DgFOsXVASDABo` | ID of the target Google Sheet containing responses. |
| `SHEET_NAME` | `Sheet1` | Name of the spreadsheet tab/worksheet. |
| `DRIVE_FOLDER_ID` | `1q0nXrlx0xHH2HKOviNEBTwHGKjDHo-vs` | ID of the target Google Drive folder where uploaded resumes (PDF/DOC) land. |
| `SHARED_TOKEN` | `"my-secret-token-123"` | Optional token matching `config.json`. Submissions with mismatched tokens return HTTP 403. |
| `ALLOWED_ORIGINS` | `https://yourusername.github.io` | Comma-separated list of allowed origin domains for advisory check. |
| `TIMESTAMP_COLUMN` | `Timestamp` | Name of the leading header column for server timestamping. |
| `NOTIFY_EMAILS` | `hr@indiamart.com` | Comma-separated list of email addresses to receive notification digests on new submissions. |

## 3. Account Rotation & Swapping Environments

To direct form submissions to a different Google Account or Google Sheet:

1. Copy `apps-script/Code.gs` and `apps-script/appsscript.json` to an Apps Script project under the new Google Account.
2. Set the `SPREADSHEET_ID` and `DRIVE_FOLDER_ID` in Script Properties under that new account.
3. Deploy as a Web App (`Execute as: Me`, `Access: Anyone`).
4. Update `endpointUrl` in `config/config.json` with the new Web App URL.
5. Push the change to GitHub — **No JavaScript code is touched**.
